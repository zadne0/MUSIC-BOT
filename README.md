# MUSIC-BOT
A bot built on Aiogram 3.x.x with the ability to search for tracks and download them directly from streaming services.
# Features
It can find music based on any request, then convert it from streaming services to mp3 format and send it to the user.
# Setup
Clone this repo: git clone ... Create .env file from .env.example. Install dependencies: pip install -r requirements.txt Run: python3 main.py
